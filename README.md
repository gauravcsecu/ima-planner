# IMA Study — GATE 2027 · MultiStream · v35

v35 adds tracked ZIP package management for Resources and PYQs.
- Resource ZIP packages tracked by package ID, name, version and topic.
- Re-importing the same Package ID replaces that package immediately.
- Packages can be removed as a whole, including their locally stored resources.
- PYQ ZIP packages have the same tracking, replacement and removal workflow.
- Package lists follow the selected topic.
- Resource, PYQ and revision lists use colorful accent borders.
- Yellow/orange note accents use dark readable text in dark/night themes.
- All data remains local to the selected course/branch.
