IMA Study — GATE 2027 Multi-Stream / GitHub Pages PWA

Included branches:
- CS/DA — existing CS/Data Science dashboard and data
- ECE — Electronics & Communication Engineering
- EE — Electrical Engineering

First launch:
1. Choose GATE.
2. Choose CS/DA, ECE or EE.
3. The selected branch gets its own local study data store.

Updating an existing installation:
- Keep the same GitHub repository and GitHub Pages URL.
- Replace the app files with the new version.
- Existing CS/DA local data is migrated automatically from the previous storage key.
- ECE and EE use separate storage, so switching branches does not mix progress, goals, bookmarks or notes.

GitHub Pages:
1. Upload the contents of this folder to the repository root.
2. Settings -> Pages -> Deploy from branch -> main -> / (root).
3. Open the HTTPS GitHub Pages URL in Chrome.
4. Use Install app / Add to Home screen.

Important:
- Do not change the GitHub Pages URL if you want existing browser local data to remain available.
- Export a Backup JSON before major updates as an extra safety measure.
