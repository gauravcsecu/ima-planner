GitHub Pages:
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Settings -> Pages -> Deploy from branch -> main -> / (root).
4. Open the generated HTTPS URL in Chrome.
5. After Chrome recognizes the PWA, use Install app / Add to Home screen.

Important: PWA installation and standalone mode require HTTPS (GitHub Pages provides HTTPS).
